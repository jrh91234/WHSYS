# รายการพาร์ทแยกแผนก (Department Part List)

ไฟล์ Part List ของแผนกผลิต (เช่น Stamping) **ไม่ใช่ BOM ของสินค้า** — ไม่มี Qty/Unit ให้ระเบิด BOM
และคอลัมน์ก็คนละผังกับ BOM เดิม จึงเก็บแยกกันคนละก้อน **แต่ค้นหารวมกันได้ในหน้า "ค้นหาพาร์ท"**

---

## ภาพรวม

| | BOM สินค้า (เดิม) | รายการพาร์ทแยกแผนก (ใหม่) |
|---|---|---|
| ชีทใน Google Sheet | ชีทละ 1 รุ่นสินค้า ชื่อชีท = ชื่อรุ่น | ชีทเดียวต่อแผนก ชื่อ `DEPT_<ชื่อแผนก>` |
| ผังคอลัมน์ | ตายตัว (C=Part No, D=Name, E=Qty, G=Type) | กำหนดเองต่อแผนกในชีท `SheetConfig` |
| ใช้ในหน้า MRP | ใช้ (ระเบิด BOM / เทียบรุ่น) | **ไม่ใช้** |
| ใช้ในหน้าค้นหาพาร์ท | ใช้ | ใช้ (มีปุ่มกรองแยกแหล่ง) |
| ใช้ในหน้าค้นหาด้วยรูป | ใช้ | ใช้ (รูปเก็บใน `PartImages` ก้อนเดียวกัน) |

พาร์ทเลขเดียวกันที่มีอยู่ทั้งสองแหล่งจะขึ้นเป็นคนละบรรทัด และมีป้าย "มีใน ... ด้วย" ให้กดสลับดู

---

## นำเข้าไฟล์ของแผนก

```bash
pip install openpyxl Pillow requests

# 1. ดูผลก่อนว่าจะได้อะไร (ยังไม่ส่งขึ้น cloud) — ได้ CSV + รูปที่ดึงออกมาไว้ตรวจ
python3 scripts/import_dept_bom.py --file Part_List_Metal_Box.xlsx --out ./out

# 2. ส่งขึ้นจริง
python3 scripts/import_dept_bom.py --file Part_List_Metal_Box.xlsx \
    --api-url "https://script.google.com/macros/s/XXXX/exec" --push
```

สคริปต์จะทำให้ 3 อย่าง:
1. สร้าง/เขียนทับชีท `DEPT_<ชื่อแผนก>` ในสเปรดชีตเดิม (รันซ้ำได้ ข้อมูลไม่ซ้อนกัน)
2. เขียนผังคอลัมน์ของแผนกนั้นลงชีท `SheetConfig`
3. ดึงรูปที่ฝังในคอลัมน์ Picture (แถวละ 1 รูป) หมุนให้ตรง แล้วอัปเข้าคลังรูปเดิม (`PartImages`)
   — พาร์ทที่มีรูปอยู่แล้วจะถูกข้าม (ใส่ `--force-images` ถ้าอยากอัปทับ)

**ขั้นตอนสุดท้ายต้องทำเอง:** เปิดหน้า "ค้นหาด้วยรูป" แล้วกด **"สร้าง/อัปเดตดัชนีรูป"** หนึ่งครั้ง
เพื่อให้รูปชุดใหม่ถูกสร้าง embedding + อ่าน OCR (โมเดลรันบนเบราว์เซอร์ สคริปต์ทำแทนไม่ได้)

ตัวเลือกอื่น: `--sheet` เลือกชีทในไฟล์, `--dept` ตั้งชื่อแผนกเอง, `--skip-images` ไม่อัปรูป

## เพิ่มแผนกใหม่ (ไม่ต้องแก้โค้ด)

ถ้าไฟล์ของแผนกใหม่มีผังคอลัมน์เหมือนไฟล์ Stamping — รันสคริปต์ด้วย `--dept <ชื่อแผนก>` ได้เลย

ถ้าผังคอลัมน์ต่างออกไป ให้แก้แถวของแผนกนั้นในชีท `SheetConfig` เอง:

| Sheet | Label | PartNoCol | NameCol | ModelCol | TypeCol | Extras |
|---|---|---|---|---|---|---|
| `DEPT_Stamping` | Stamping | D | C | B | J | `F:Spec,G:ขนาด,H:Step,I:Tooling No.,K:เครื่อง/Machine` |

- คอลัมน์กรอกได้ทั้งตัวอักษร (`D`) และเลข index นับจาก 0 (`3`)
- `Extras` = ฟิลด์เพิ่มที่จะโชว์ตอนกด "ดูข้อมูลงานผลิต" เขียนเป็น `คอลัมน์:ชื่อที่จะโชว์` คั่นด้วย comma
- ไม่มีแถวใน `SheetConfig` → ระบบใช้ผังเริ่มต้น (`DEPT_COLS_DEFAULT` ใน `index.html`) ซึ่งตรงกับไฟล์ Stamping

## หมายเหตุ

- Part No จาก Excel มัก **มีอักขระที่มองไม่เห็นติดมา** (non-breaking space, zero-width, ขึ้นบรรทัดใหม่ท้ายเซลล์)
  ซึ่ง `.trim()` ธรรมดาไม่กิน — ระบบล้างด้วย `cleanPartNo()` / `normPartNo()` ทั้งตอนนำเข้าและตอนค้นหา
  ทำให้พิมพ์เลขพาร์ทตรง ๆ แล้วเจอเสมอ ไม่ว่าในชีทจะสกปรกแค่ไหน
- ค้นหาพาร์ทของแผนก **ค้นด้วยเลขแม่พิมพ์ (Tooling No.) / Process / ขนาด ได้ด้วย** ไม่ใช่แค่เลขพาร์ทกับชื่อ
- ชีทที่ระบบถือว่าไม่ใช่ BOM: `Inventory`, `Transactions`, `Users`, `PartImages`, `NegativeExamples`, `SheetConfig`
  และทุกชีทที่ขึ้นต้นด้วย `DEPT_`
